# 霞智 2026

霞智 2026 是一个机器人研究项目，旨在利用现有模块化系统采集的数据，学习可复用的端到端策略。

## 项目概述

上一阶段已通过模块化机器人系统实现三种常规任务。2026 阶段将复用该系统采集的数据，训练并评估端到端策略。

项目还将引入三种差异化任务，探索结合以下方法完成任务：

- 视觉—语言—动作模型（VLA）
- 世界动作模型（WAM）
- 强化学习（RL）

## 项目目标

### 三种常规任务

- 复现上一阶段已经实现的三种任务。
- 整理并复用模块化系统采集的数据。
- 基于已有数据训练端到端策略。
- 将学习得到的策略与现有模块化基线进行比较。

### 三种差异化任务

- 定义并实现三种需要更强学习能力的差异化任务。
- 探索基于 VLA、WAM 和 RL 的任务解决方案。

### 2+1 泛化

核心泛化实验包含三种场景：

1. 在前两种场景中采集数据并进行训练。
2. 将学习得到的策略或表征迁移到第三种场景。
3. 评估前两种场景的数据能否帮助第三种场景的策略训练与部署。

该实验旨在验证项目方法能否在相关部署场景之间实现泛化，而不是分别为每个场景独立构建解决方案。

## 项目背景

本项目由霞智具身智能团队与上海交通大学合作开展。当前数据采集硬件基线为 RealMan ECO63 一体化六维力版本和 3 台 Orbbec Gemini 335，相应软件运行在 ROS 2 Humble 下。
